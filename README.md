# ColinHack

**ColinHack** is a lightweight yet powerful utility client designed for Minecraft 26.1.2. Built on the Fabric Loader, it provides a suite of essential features to enhance your gameplay experience, ranging from advanced combat mechanics to world manipulation and movement improvements.

## Features & Modules

The client is organized into several categories, each containing specialized modules:

### Combat
*   **AimBot**: Automatically assists in aiming at targets.
*   **AutoClicker**: Automates mouse clicks at a customizable speed.
*   **KillAura**: Automatically attacks entities within range.

### Movement
*   **Fly**: Grants the ability to fly in any game mode.
*   **Jesus**: Allows walking on water and other liquids.
*   **Speed**: Enhances movement speed for faster travel.
*   **Step**: Enables instant stepping up full blocks.

### Player
*   **NoFall**: Prevents taking damage from falling.

### Render
*   **ESP**: Highlights entities through walls.
*   **FullBright**: Maximizes brightness, making everything visible in the dark.
*   **Tracers**: Draws lines to nearby players or entities.

### World
*   **Scaffold**: Automatically places blocks beneath you while moving.
*   **Timer**: Adjusts the game's tick rate to speed up or slow down time.
*   **XRay**: Renders specific blocks visible through solid terrain for easy resource finding.

## Technical Details
*   **Minecraft Version**: 26.1.2
*   **Loader**: Fabric
*   **Java Version**: 25 or higher

## Installation
1.  Ensure you have the [Fabric Loader](https://fabricmc.net/) installed for Minecraft 26.1.2.
2.  Download the latest release of ColinHack.
3.  Place the `.jar` file into your Minecraft `mods` folder.
4.  Launch the game using the Fabric profile.
